Tentang Saya

Perkenalkan, saya Havis Hidayat, siswa dari kelas X.U-4. Saya menyukai kegiatan belajar yang berhubungan dengan komputer dan teknologi digital. Dalam pelajaran Web Design, saya sedang mencoba memahami cara membuat halaman web dari awal, mulai dari menulis struktur menggunakan HTML sampai menghias tampilan menggunakan CSS. Bagi saya, membuat website adalah kegiatan yang menarik karena sebuah ide dapat diubah menjadi halaman yang bisa dilihat dan digunakan oleh banyak orang.

Target saya dalam pelaksanaan PSTS Ganjil adalah menyelesaikan tugas ini dengan hasil yang maksimal serta memahami setiap proses pembuatannya. Saya ingin dapat menggunakan Git untuk mencatat perkembangan proyek, membuat branch untuk mencoba fitur baru, dan menggabungkan perubahan dengan benar ke branch utama. Selain itu, saya ingin berhasil mempublikasikan halaman portofolio ini melalui GitHub Pages sebagai bukti bahwa saya telah menyelesaikan pembelajaran Web Design.
